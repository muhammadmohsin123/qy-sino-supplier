# QY Sino Supplier

Company website and profile for **QY Sino Supplier**, general order suppliers based on Jhang Road, Muzaffargarh, Punjab.

## Contents

- `index.html` — single-page company website (static HTML/CSS, no build step)
- `img/` — website photography (Unsplash)
- `docs/QY-Sino-Supplier-Company-Profile.pdf` — 16-page company profile

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Static site, deployable as-is to GitHub Pages, Netlify, Vercel or any web host. For GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
